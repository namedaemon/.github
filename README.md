# NameDaemon

Free tools for .com domain names, built on a daily snapshot of the whole .com zone: check availability, score a brand name, get two-word ideas and compare what an extension really costs.

Website and free tools: https://namedaemon.com · For developers: https://namedaemon.com/developers/

## Packages

| Where | Install | Repo |
| --- | --- | --- |
| npm | `npm install namedaemon` | [namedaemon-npm](https://github.com/namedaemon/namedaemon-npm) |
| PyPI | `pip install namedaemon` | [namedaemon-pypi](https://github.com/namedaemon/namedaemon-pypi) |
| Composer (PHP, Laravel) | `composer require namedaemon/namedaemon` | [namedaemon-php](https://github.com/namedaemon/namedaemon-php) |
| RubyGems | `gem install namedaemon` | [namedaemon-ruby](https://github.com/namedaemon/namedaemon-ruby) |
| Go and Homebrew | `brew install namedaemon/namedaemon/namedaemon` | [namedaemon-go](https://github.com/namedaemon/namedaemon-go) |

All are MIT licensed, free, need no API key and share a limit of about 20 requests a minute per address.

Questions or a missing method? Open an issue on the package, or write to support@namedaemon.com.
